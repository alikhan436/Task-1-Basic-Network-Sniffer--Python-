# CodeAlpha Internship - Task 1: Basic Network Sniffer

A Python-based network sniffer built using `scapy` to capture and analyze network packets in real-time.

## Features
- **IP Address Extraction**: Captures and logs source and destination IP addresses.
- **Protocol Identification**: Identifies packet protocols (e.g., TCP, UDP, ICMP).
- **Payload Inspection**: Displays raw payload snippets when available.
- **Packet Count Threshold**: Automatically captures and processes a set batch of packets (20 packets).

## Prerequisites
- **Python**: Python 3.x installed.
- **Dependencies**: Scapy library (`pip install scapy`).
- **Privileges**: Administrator / root privileges are required to capture network interfaces.
